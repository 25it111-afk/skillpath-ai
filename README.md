## The problem
Students know the career they want but not which skills it requires, where they stand, or what to learn first. They follow generic roadmaps that ignore their own level, and static plans never adapt as they improve or struggle. First-generation learners and students in tier-2/tier-3 colleges, who often have no mentor, and college placement cells (who see skill gaps only when placements begin) are affected most. The result is wasted learning time and gaps discovered only in interviews.

## Our solution
SkillPath AI takes a student's **target role**, assesses their **current skills**, finds the **skill gaps** against the role's requirements, and generates a **personalized week-by-week roadmap**. As the student practices, an **adaptive engine** updates their scores, flags weak topics for revision and reshapes the roadmap.

```
Student → Target role → Skill assessment → Skill-gap analysis
        → AI roadmap (Gemini) → Practice → Adaptive update → New roadmap
```

## Features
- 🔐 **Secure accounts:** register/login with bcrypt-hashed passwords and JWT sessions
- 🎯 **Role selection:** Software Engineer, Data Analyst, Web Developer (each with its own skill requirements)
- 🧪 **Skill assessment:** quiz plus self-rating across DSA, Programming, SQL, Git and CS Fundamentals
- 📊 **Skill-gap analysis:** your score vs. the role's required level, with strengths and priority gaps
- 🗺️ **Personalized roadmap:** week-by-week topics, practice tasks and projects generated by the Gemini API
- 🔄 **Adaptive learning engine:** practice results update skill scores, mark topics done or weak, and change the next roadmap
- 🛟 **Resilient by design:** if the Gemini API is unavailable, a rule-based generator returns a roadmap so the app never breaks
- 📈 **Career readiness dashboard:** overall readiness percentage and per-skill progress

## How the adaptive engine works
After each practice session (problems solved out of 5):

```
new_score = 0.7 × old_score + 0.3 × practice_result
solved ≥ 3/5  → topic marked DONE, removed from the roadmap
solved < 3/5  → topic marked WEAK, placed first for revision
```
The roadmap is regenerated from the updated scores and the done/weak lists, so the plan always reflects current performance.

## Architecture
```
 Browser (HTML/CSS/JS)  ──REST + JWT──►  Node.js / Express API
                                           ├─ Auth routes (bcrypt, JWT)
                                           ├─ Roadmap route ──► Gemini API
                                           │                    └─ rule-based fallback
                                           └─ MongoDB Atlas (users, scores, roadmap, progress)
```

## Tech stack
| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript (single-page app) |
| Backend | Node.js, Express.js (REST API) |
| AI | Google Gemini API (roadmap generation) + rule-based adaptive engine |
| Database | MongoDB Atlas (Mongoose) |
| Auth | JWT, bcrypt |
| Deployment | Render (API), Netlify/Vercel (frontend) |

## API endpoints
| Method | Route | Auth | Purpose |
|---|---|---|---|
| POST | `/api/auth/register` | – | Create an account |
| POST | `/api/auth/login` | – | Log in, returns JWT |
| POST | `/api/roadmap/generate` | ✔ | Skill-gap analysis + roadmap |
| POST | `/api/roadmap/practice` | ✔ | Submit practice result, update scores |
| GET | `/api/roadmap/me` | ✔ | Load saved roadmap |
| GET | `/api/health` | – | Health check |

## Run locally
```bash
git clone https://github.com/<your-username>/skillpath-ai.git
cd skillpath-ai/server
npm install
```
Create `server/.env`:
```
PORT=5000
MONGO_URI=<your MongoDB Atlas connection string>
JWT_SECRET=<long random string>
GEMINI_API_KEY=<your Gemini API key>
GEMINI_MODEL=gemini-2.5-flash
```
```bash
npm run dev          # API on http://localhost:5000
```
Then open `client/index.html` in your browser. The `API` constant at the top of that file points to the backend URL.

## Real-world impact & scalability
- Gives students without mentors clear, personalized direction.
- Roles, skills and topics are data-driven (`server/lib/data.js`), so new careers can be added without code changes.
- Planned: resume analysis, job-description matching, mock interviews, coding-platform integration, and a **placement-cell dashboard** for college-level skill analytics.
